# Discovery

What `/product` has learned from **adjacent apps and tooling**: journaling, lifelog, habit-free
trackers, personal knowledge tools, hobby communities, and the Expo/React Native/web platform
capabilities that could make Wanderment better. It's kept so that research is done once and
reused.

One file per investigation: `YYYY-MM-DD-topic.md`, written by `/product` from a `product-scout`
report. Each file ends with **Borrowable ideas**. Every idea is checked against DESIGN.md and
STRATEGY.md and given one of these verdicts:
- **Fits**, which becomes a roadmap item or a brief;
- **Fits if changed**, which says how;
- **Doesn't fit**, which says which rule it breaks. These are kept, so the same idea isn't
  re-proposed.

Sources are linked. Claims about other products are dated, because apps change.
